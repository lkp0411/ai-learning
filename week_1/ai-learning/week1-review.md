## 2. 哪一步最卡？卡了多久？怎么解决的？

**最卡的一次：pandas 明明装了，脚本还是报 `ModuleNotFoundError`。卡了大约 1.5 小时。**

当时的困惑是：终端里 `pip install pandas` 明明跑完还显示 success，可一运行脚本就说没有 pandas。我反复装了三遍。

真正的原因是——**装到了另一个 Python 里**：

- 终端里那个 `pip` 属于 conda 的 `base` 环境（Python 3.14）
- VS Code 编辑器选的解释器是 `Python310`（系统那个，没装 pandas）
- 两个是完全不同的柜子，我在 A 柜放了东西，却去 B 柜找

决定性证据是 pip 输出里那两行：

```
Downloading pandas-3.1.1-cp314-cp314-win_amd64.whl      ← cp314 = Python 3.14
Requirement already satisfied: numpy>=2.3.3 in C:\Users\27200\miniconda3\Lib\site-packages
```

`cp314` 和 `miniconda3\Lib\site-packages` 一起出现，就说明东西进了 base。

解决：建一个专用环境 `conda create -n ai python=3.11`，在**那个环境里**装包，然后把 VS Code 的解释器也指到同一个 `envs\ai\python.exe`。之后**铁律：装包一律用 `python -m pip install xxx`**，这样 pip 一定是"当前这个 python"的 pip，装不错柜子。

**另外三个小坑：**

| 卡点 | 卡多久 | 原因 | 解法 |
|---|---|---|---|
| 文件 `11.19` 满屏红波浪线（9 个错误） | 约 20 分钟 | 文件没有扩展名，VS Code 猜成 Python，把 shell 命令当语法错误 | 改名 `11.19.md`，它本来就是笔记 |
| `git commit -m "中文"` 提交信息变乱码 `鍩庡競 GDP...` | 约 30 分钟 | PowerShell 5.1 把参数按 GBK 传给 git | 用 `git commit -F 信息.txt`（文件存 UTF-8） |
| 找不到 `gdp.csv`，明明和 .py 在同一个文件夹 | 约 20 分钟 | 不是文件位置问题，是**工作目录**问题——`"gdp.csv"` 是相对当前终端目录解析的 | `Path(__file__).with_name("gdp.csv")`，与在哪运行无关 |

这个问题给我的最大教训：**报错先看它说的是哪个 python、哪个路径**，别急着重装。

## 4. 下周我最想搞懂的一件事是什么？

**为什么我的线性回归训练会发散。**

今天 `train_linear.py` 跑通了、GPU 也真的在算，但结果荒谬——损失从 652 一路涨到 **2.77 亿**，学到的 `w = -1744.95`（真实值是 3）。

我做了个对照实验，把原因钉死了：

| 方案 | 第 100 轮 loss | 学到的 w | 学到的 b |
|---|---|---|---|
| 原样（lr=0.01，X 不标准化） | 1.38e11 | -39871 | -140 |
| lr=0.002，500 轮 | **3.48** | **2.9775** | **1.9474** |
| 标准化 X + lr=0.1 | 3.34 | 2.9762 | 2.3194 |

原因是我的 `X = torch.randn(100,1) * 10`，数值范围到 ±30，而学习率 0.01 对这么大的输入来说等于一步迈太大，直接冲过了谷底，越飞越远。

所以下周想搞懂两件事：
1. **学习率、数据尺度、梯度大小三者的关系**——为什么 `X*10` 会让 lr 需要缩小 100 倍左右（大约和 X 的方差成正比）。
2. **`nn.Module` 怎么写自己的模型**——现在只会用 `nn.Linear`，想自己定义一个类。
